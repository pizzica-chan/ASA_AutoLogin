このツールについて

ASA_Login は、接続先サーバーをあらかじめ選択した状態から、 JOIN ボタンのクリック〜ログイン待ち〜失敗時の復帰までを自動で繰り返すツールです。

ツールが行うこと
  • サーバー一覧の JOIN →（必要なら）MODS の JOIN → ログイン待ち
  • 満員などで失敗したときの CANCEL / BACK / JOIN GAME による復帰と再試行
  • タイトル画面での NETWORK FAILURE 処理（ACCEPT → Space → JOIN GAME）
ツールが行わないこと
  • SESSION NAME によるサーバー検索
  • Official / Unofficial などのサーバータブ切り替え
  • サーバー行の選択（ユーザーが手動で選択してください）

インストールと起動

配布版（Python 不要・推奨）

  1. ASA_Login-win64.zip を任意のフォルダに展開します。
  2. ASA_Login.exe をダブルクリックして起動します。
  3. 初回起動時に config.yaml と templates/ が自動作成されます。

展開後のフォルダ構成の例:

ASA_Login/
  ASA_Login.exe
  config.example.yaml
  config.yaml          … 初回起動で自動生成
  templates/           … 画面キャプチャ（セットアップで作成）
  templates/buttons/   … ボタン認識用 PNG
  logs/                … ログファイル
  使い方.txt

開発版（Python あり）

pip install -r requirements.txt
python gui.py

クイックスタート

  1. ARK を起動し、マルチプレイのサーバー一覧を表示します。
  2. 接続したいサーバーの行をクリックしてオレンジ色で選択します。
  3. ASA_Login の 「セットアップ」 を押し、最小モード（推奨） で ① サーバー一覧を登録します。
  4. ARK を表示しているモニターを GUI の 「ARK を表示しているモニター」 で選びます。
  5. 「開始」 を押し、確認ダイアログの指示どおりの状態であることを確認して実行します。
最小セットアップのポイント
① サーバー一覧のキャプチャだけで動作します。CANCEL / BACK / MODS JOIN などのボタンは 同梱のボタン画像で自動検出するため、わざとエラー画面を起こしてキャプチャする必要はありません。

自動化の流れ（①〜⑦）

1 回の接続試行は ① → ②（任意）→ ③ です。失敗した場合は復帰ルートに入り、再び ① から繰り返します。

① サーバー一覧（選択済み）→ 右下 JOIN
        ↓
② REQUIRED MODS（表示された場合のみ）→ 左下 JOIN
        ↓
③ ログイン試行（待機）
   ├─ 成功（ゲーム内画面を検出）→ 完了
   ├─ ③-A CONNECTION FAILED → CANCEL → ④ BACK → ⑤ JOIN GAME → ①
   └─ ⑥ NETWORK FAILURE → ACCEPT → ⑦ Space → ⑤ JOIN GAME → ①
番号 画面 操作 備考
① サーバー一覧 右下の JOIN をクリック サーバーは事前選択済みであること
② REQUIRED MODS モーダル左下の JOIN 出ないサーバーはスキップ
③ ログイン処理中 待機のみ 成功・失敗・動画のいずれかを監視
③-A CONNECTION FAILED CANCEL（ACCEPT は使わない） サーバー一覧上のダイアログ
④ 空のサーバー一覧 左下の BACK MULTIPLAYER SERVERS: 0 など
⑤ メインメニュー JOIN GAME カードをクリック ④枚 / ⑤枚タイルに対応
⑥ NETWORK FAILURE ACCEPT タイトル画面のダイアログ
⑦ タイトル画面 Space キー ⑤ と同様に JOIN GAME へ

⑤ メインメニューの例（④枚タイル）

各操作で使うボタン画像

クリック対象は templates/buttons/ 内の PNG を画面上から検索して押します（座標フォールバックあり）。

リトライ設定

  • 最大試行回数 … 0 のとき成功するまで無制限に繰り返します。
  • リトライ間隔 … 失敗して ① に戻ったあと、次の試行まで待つ秒数です。

セットアップ

GUI の 「セットアップ」 ボタンから、画面キャプチャとクリック座標を登録します。

最小モード（推奨）

① サーバー一覧だけ登録すれば動作します。
エラー系のボタンは同梱 PNG で検出するため、CONNECTION FAILED などの画面をわざと起こす必要はありません。

フルモード

解像度や UI レイアウトが大きく異なる環境向けです。各画面を個別にキャプチャし、精度を上げられます。

ステップ 保存ファイル クリック登録
① サーバー一覧 templates/server_list.png 右下 JOIN
② MODS（任意） templates/required_mods.png 左下 JOIN
③-A CONNECTION FAILED templates/connection_failed.png CANCEL
④ 空のサーバー一覧 templates/server_list_empty.png BACK
⑤ メインメニュー templates/main_menu.png JOIN GAME
⑥ NETWORK FAILURE templates/network_failure.png ACCEPT
⑦ タイトル画面（任意） templates/title_screen.png —（Space キー）
成功判定（推奨） templates/in_game.png —
再セットアップが必要なタイミング
  • ゲームの解像度や表示モードを変更したとき
  • モニターの割り当てを変えたとき
  • UI スケールや言語設定を変えたとき

GUI の各タブ

メイン 基本設定

  • 注意事項 … 動作前の確認ポイント
  • ARK を表示しているモニター … サブモニター運用時はここで対象を選択
  • 最大試行回数 / リトライ間隔 … 失敗時の繰り返し設定

待ち時間 場面ごとの待機

①〜⑦ の各場面で、どれくらい待つかを細かく調整できます。読み込みが遅い PC では少し長めにすると安定しやすいです。

項目説明
開始までの待ち「開始」押下後、実際の操作を始めるまでの秒数
画面チェック間隔ボタン・画面状態を確認する間隔（短いほど反応は早い）
クリック前 / 後の待ちボタン検出からクリックまで、およびクリック後の安定待ち
② MODS 画面の確認時間① JOIN 後、MODS が出るかどうか見る時間
③ ログイン結果の待ち成功・失敗・動画のいずれかが出るまでの上限
失敗後の画面復帰待ちCANCEL / BACK / ACCEPT 後の復帰待ち上限

画像認識 一致度の調整

  • 画面判定の一致度 … サーバー一覧やメインメニューなど全体画面の判定
  • ボタン判定の一致度 … JOIN / CANCEL などボタン画像の判定
  • ② MODS 画面の一致度 … MODS の出現判定（低めの値がデフォルト）
  • ARK ウィンドウのタイトル … 通常は変更不要
  • 操作前に ARK を前面に出す … サブモニター運用ではオン推奨

誤クリックが多い → 一致度を上げる。見逃しが多い → 一致度を下げる。

クリック座標 ％座標とクリック方式

左上 (0, 0)、右下 (100, 100) のパーセント座標で各ボタンの位置を指定します。セットアップで登録した値もここに反映されます。

クリック方式動作
画像優先 ボタン画像が見つかればその位置をクリック。見つからなければ登録座標
画像のみ 画像が見つからない場合は座標にフォールバックしない
座標優先 登録座標を優先（画像は補助）
座標のみ クリックはすべて座標。画像認識は画面遷移の判定のみに使用

座標プレビュー ボタンで、設定した位置をモニター上に点表示して確認できます。

ログエリア

  • ログ … 進行状況のわかりやすい表示（通常はこちら）
  • 詳細ログ … 類似度・座標など技術情報（原因調査用）

ボタン画像の差し替え

実行時に参照するのは templates/buttons/ 内の PNG です。 初回起動時に assets/defaults/buttons/（配布版では同梱データ）からコピーされます。

  1. ゲーム画面で対象ボタン部分を切り出した PNG を用意します。
  2. templates/buttons/ に同じファイル名で上書き保存します。
  3. ASA_Login を再起動するか、次の試行から反映されます。
主なファイル名
  • join_server_list.png … ① サーバー一覧 JOIN
  • join_mods.png … ② MODS JOIN
  • cancel_failed.png … ③-A CANCEL
  • back_empty_list.png … ④ BACK
  • join_game.png … ⑤ JOIN GAME（④枚タイル）
  • join_game_center.png … ⑤ JOIN GAME（⑤枚タイル）
  • accept_network_failure.png … ⑥ ACCEPT
初回コピー後は既存ファイルを上書きしません。古い PNG が残っている場合は手動で差し替えてください。 ⑤枚タイルレイアウトで JOIN GAME が押せない場合は join_game_center.png を ご自身の画面から切り出して差し替えてください。

ログの見方

出力先内容
GUI「ログ」タブ 今どの段階か、成功・失敗などユーザー向けメッセージ
GUI「詳細ログ」タブ 画像一致度、検出座標、状態遷移の詳細
logs/asa_login_user.log ユーザー向けログのファイル保存
logs/asa_login_detail.log 詳細ログのファイル保存

問題が起きたときは、まず「ログ」タブで止まっている段階を確認し、必要なら「詳細ログ」で一致度を調べてください。

うまくいかないとき

ボタンを押せない・押す位置がずれる

  • 「画像認識」タブでボタン判定の一致度を調整する
  • 「クリック座標」タブで座標を微調整、または「座標プレビュー」で確認する
  • templates/buttons/ の PNG を自分の画面から切り出して差し替える
  • 解像度変更後はセットアップをやり直す

画面の判定が合わない

  • セットアップで ①（必要なら他画面も）を再キャプチャする
  • 画面判定の一致度を下げる（ただし誤判定も増えやすい）

サブモニターで動かない

  • 「ARK を表示しているモニター」が正しいか確認する
  • 「操作前に ARK を前面に出す」をオンにする
  • ARK が他ウィンドウに隠れていないか確認する

③ で長く待たされる

  • 「待ち時間」タブのログイン結果待ち・動画待ちを確認する
  • ログイン動画が流れるサーバーでは時間がかかることがあります

設定をファイルで編集したい

config.yaml をテキストエディタで編集できます。雛形は config.example.yaml を参照してください。GUI で「設定を保存」を押すとファイルに書き戻されます。

注意事項

  • 接続先サーバーは必ず手動で選択してください（オレンジ色のハイライト）。
  • 操作時に ARK ウィンドウが一瞬前面に出ます（完全なバックグラウンド動作ではありません）。
  • ゲームの利用規約に違反する可能性があります。自己責任でご使用ください。
  • Windows 10 / 11（64bit）向けです。

技術的なフロー仕様の詳細は docs/FLOW.md も参照してください。
